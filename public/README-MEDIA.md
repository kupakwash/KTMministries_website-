# Your content checklist

Add the following files when ready; the website is already configured to use them.

- `photos/hero.jpg` — wide high-quality hero image or video poster (2400px+ wide).
- `photos/founder.jpg` — vertical professional portrait.
- `photos/conference.jpg` — conference/preaching image.
- `photos/invite.jpg` — wide speaking event image.
- `photos/journal-purpose.jpg`, `photos/journal-leadership.jpg`, `photos/journal-ai.jpg` — article images.
- `videos/sermon-poster.jpg` — thumbnail for the featured sermon, then replace the play link with the video URL in `app/page.tsx`.
- `book/gps-cover.jpg` — final book cover; replace the illustrated book block in `app/page.tsx` to use it.

Also replace links marked `#`, social account URLs, email address, biography, sermon titles, journal copy, prices, payment/order form, and order fulfilment links before launch.
